# Econometrics Projects & Assignments

This repository contains my academic assignments and research models developed during my Economics (Honors) degree at Narsingdi Govt. College.

### Key Methodologies Applied:
* **Ordinary Least Squares (OLS) Regression:** Applied to estimate the relationships between economic variables and test for statistical significance.
* **Time Series Analysis:** Analyzed historical economic datasets to identify trends, seasonality, and forecasting behaviors.
* **Hypothesis Testing:** Conducted t-tests, F-tests, and chi-square tests for econometrics model validation.

*All assignments are uploaded in PDF format for detailed review.*
